# Day 02 - Python Fundamentals

## Overview

This folder contains the Python programming assignments completed on Day 02 of the AIML Internship Program.

The objective of these tasks was to build a strong foundation in Python programming by practicing variables, data structures, conditional statements, loops, functions, user input handling, dictionaries, and basic problem-solving techniques.

As a beginner in programming, these exercises helped me understand how Python can be used to solve real-world problems through logical thinking and structured code.

---

## Learning Objectives

During Day 02, I focused on:

* Python syntax and basic programming concepts
* Variables and data types
* Conditional statements
* Loops and iteration
* Functions
* Dictionaries and lists
* String manipulation
* User input handling
* Basic problem-solving approaches

---

## Files Included

### 1. intro.py

A simple Python program that introduces a student using variables, dictionaries, and formatted strings.

**Concepts Practiced:**

* Variables
* Dictionaries
* f-strings
* Data representation

---

### 2. skills_counter.py

Displays a list of skills and calculates the total number of skills.

**Concepts Practiced:**

* Lists
* Loops
* Counting elements
* Output formatting

---

### 3. even_odd.py

Determines whether a given number is even, odd, or zero.

**Concepts Practiced:**

* Conditional statements
* Modulus operator
* User input

---

### 4. tip_calculator.py

Calculates the tip amount and total restaurant bill.

**Concepts Practiced:**

* Functions
* Arithmetic operations
* Dictionaries
* User input handling

---

### 5. word_frequency.py

Counts the frequency of words in a sentence.

**Concepts Practiced:**

* Strings
* Dictionaries
* Loops
* Frequency counting

---

### 6. calculator.py

A basic calculator that performs arithmetic operations.

**Concepts Practiced:**

* Functions
* Conditional logic
* Mathematical operations

---

### 7. grade_classifier.py

Classifies students into different grades based on their marks.

**Concepts Practiced:**

* If-else statements
* Logical conditions
* Decision making

---

### 8. guessing_game.py

A number guessing game where the user attempts to guess a randomly generated number.

**Concepts Practiced:**

* Loops
* Random module
* User interaction
* Conditional statements

---

### 9. contact_book.py

Searches for contact information using case-insensitive matching.

**Concepts Practiced:**

* Dictionaries
* String manipulation
* Search functionality
