# Day 10 - Advanced Pandas, Data Visualization & SQL Analysis

## Overview

This folder contains the Day 10 assignment completed as part of the AIML Internship Program.

The objective of this assignment was to perform end-to-end data analysis using Pandas, create visualizations, calculate business metrics, and work with SQL databases for querying and reporting.

This was one of my first assignments involving real-world style data analysis workflows, including data cleaning, aggregation, visualization, and SQL-based analysis.

---

During Day 10, I focused on:

* Advanced Pandas Operations

* Exploratory Data Analysis (EDA)
