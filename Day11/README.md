# Day 11 - Mathematics for Machine Learning & Exploratory Data Analysis

## Overview

This folder contains the Day 11 assignment completed as part of the AIML Internship Program.

The objective of this assignment was to understand important mathematical concepts used in Machine Learning and apply them using Python. The notebook combines mathematical computations, data visualization, statistical analysis, and basic Exploratory Data Analysis (EDA).

This assignment helped bridge the gap between theoretical mathematics and practical Machine Learning applications.
