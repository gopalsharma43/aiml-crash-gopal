# AIML Crash Course - Gopal Sharma

This repository contains Python practice tasks completed during the AI/ML internship training.

## Tasks Completed

### 1. intro.py
Prints a student introduction using variables, dictionaries, and f-strings.

### 2. skills_counter.py
Prints a numbered list of skills and counts total skills.

### 3. even_odd.py
Checks whether a number is even, odd, or zero with error handling.

### 4. tip_calculator.py
Calculates tip amount and total bill using functions and dictionaries.

### 5. word_frequency.py
Counts how many times each word appears in a sentence.

### 6. calculator.py
Performs addition, subtraction, multiplication, and division operations.

### 7. grade_classifier.py
Classifies student grades based on scores and sorts them.

### 8. guessing_game.py
A number guessing game using loops and random numbers.

### 9. contact_book.py
Searches contacts from a mini contact book using case-insensitive matching.
