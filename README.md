# AIML Crash Course - Gopal Sharma

This repository contains Python assignments completed as part of the AIML Internship Program. The tasks cover Python fundamentals, Object-Oriented Programming (OOP), File Handling, JSON, CSV, Pandas, Git, and GitHub workflows.

---

## Technologies Used

* Python 3.11
* Pandas
* NumPy
* CSV Handling
* JSON Handling
* Git
* GitHub
* VS Code

---

# Day 2 Tasks

### 1. intro.py

Student introduction using variables, dictionaries, and f-strings.

### 2. skills_counter.py

Displays a numbered list of skills and counts the total number of skills.

### 3. even_odd.py

Checks whether a number is even, odd, or zero.

### 4. tip_calculator.py

Calculates tip amount and total bill using functions and dictionaries.

### 5. word_frequency.py

Counts the frequency of words in a sentence.

### 6. calculator.py

Performs basic arithmetic operations.

### 7. grade_classifier.py

Classifies students into grades based on their marks.

### 8. guessing_game.py

A simple number guessing game using loops and random numbers.

### 9. contact_book.py

Searches contacts using case-insensitive matching.

---

# Day 4 Tasks

### 1. student_report.py

Implements a Student class with methods to calculate average marks and grades.

### 2. comprehension_drills.py

Demonstrates list, dictionary, and set comprehensions.

### 3. file_records.py

Reads student records from CSV, calculates averages and grades, and generates a results CSV file.

### 4. typed_calculator.py

Calculator module using type hints, docstrings, and optional return types.

### 5. library_system.py

Demonstrates inheritance through LibraryItem, Book, and EBook classes.

### 6. config_manager.py

Manages application configuration using JSON files.

### 7. pandas_explore.py

Performs basic data analysis using the Pandas library.

### 8. fraction_class.py

Implements a Fraction class with operator overloading and dunder methods.

### 9. inventory.py

Mini inventory management system using OOP and CSV file handling.

---

# Day 7 Tasks

### 1. profile_card.py
Creates a student profile card using dictionaries, type hints, and f-strings.

### 2. json_report.py
Loads data from a JSON file and generates a formatted learner report.

### 3. course_tracker.py
Tracks course completion progress using a custom class and methods.

### 4. config_updater.py
Reads and updates application settings stored in a JSON file.

### 5. data_summary.py
Performs basic data analysis using Pandas and calculates averages.

### 6. numpy_basics.py
Demonstrates NumPy array creation and mathematical operations.

### 7. student_scores.py
Analyzes student scores using NumPy functions.

### 8. employee_data.py
Uses Pandas to analyze employee salary information.

### 9. student_dashboard.py
Builds a mini student dashboard using Pandas DataFrames.
