# Linear Regression Practical Tasks

## Project Overview

This project demonstrates the implementation and evaluation of Linear Regression using the California Housing Dataset. The objective is to understand model training, performance evaluation, feature selection, train-test split effects, and regression metrics.

## Dataset

Dataset: California Housing Dataset

Source:
Scikit-Learn California Housing Dataset

Target Variable:

* MedHouseVal (Median House Value)

## Tasks Completed

### Task 1: Baseline Linear Regression Model

* Loaded dataset
* Split into training and testing sets
* Trained Linear Regression model
* Generated predictions
* Evaluated model using MSE, RMSE, MAE, and R²
* Compared Actual vs Predicted values

### Task 2: One-Feature vs Multi-Feature Model

* Model A: Single Feature (MedInc)
* Model B: Multiple Features
* Compared performance using regression metrics
* Selected the better-performing model

### Task 3: Train/Test Split Analysis

* Evaluated model using:

  * 80/20 Split
  * 70/30 Split
  * 60/40 Split
* Compared training and testing performance
* Analyzed model stability

### Task 4: Metric Verification and Exploration

* Calculated metrics manually
* Verified results with sklearn
* Added Median Absolute Error
* Performed artificial error experiment
* Studied metric sensitivity to outliers
