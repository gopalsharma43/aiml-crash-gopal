# Day 04 - Intermediate Python, OOP, File Handling & Pandas

## Overview

This folder contains the assignments completed on Day 04 of the AIML Internship Program.

The objective of these tasks was to move beyond basic Python programming and explore more advanced concepts such as Object-Oriented Programming (OOP), file handling, JSON and CSV processing, comprehensions, type hints, operator overloading, inheritance, and introductory data analysis using Pandas.

These exercises helped me understand how Python is used to build structured applications and process real-world data.

---

## Learning Objectives

During Day 04, I focused on:

* Object-Oriented Programming (OOP)
* Classes and Objects
* Inheritance
* Operator Overloading
* File Handling
* CSV Processing
* JSON Processing
* Type Hints and Documentation
* Python Comprehensions
* Data Analysis using Pandas
